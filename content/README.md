# محتوى منصة نَحْو

هذا المجلد هو المصدر الوحيد للمحتوى. كل ما في `data/` مولّد آليًا ولا يُعدّل يدويًا.

## الملفات

- `lessons.json` — بيانات الدروس الـ٥٣ (المعرف، العنوان، القسم، حالة الجاهزية)، ومحتوى الدروس الجاهزة كاملًا.
  - الدروس **١–٥** (`الكلمة وأنواعها`، `علامات الاسم`، `علامات الفعل`، `علامات الحرف`، `التعريف والتنكير`) منشورة بمحتواها الكامل: شرحٌ وجدول قاعدة وخمسة أمثلة معربة وصندوق «تذكّر».
  - بقية الدروس `ready: false` فتظهر للطالب بصفحة «قيد الإعداد».
- `passages/L01 … L05` — خمسة ملفات مستويات لكل درس جاهز (١٠ قطع لكل مستوى). تُضاف على دفعات في الحزمة السادسة.
  - `passages/L01` — **بنك مسوّدة** (`"draft": true` في كل ملف): ٣ قطع في كل مستوى = ١٥ قطعة و٤٥ سؤالًا للدرس الأول، لتعمل دورة التدريب كاملةً. يُستكمل إلى ١٠ قطع لكل مستوى في الحزمة السادسة بحذف العلامة.
- `passages/_template/level.template.json` — قالب مثالي يُنسخ للبدء بملف مستوى جديد.

## التحقق والبناء

```bash
python3 tools/validate_content.py   # فحص وتقرير
python3 tools/build_data.py         # فحص ثم توليد data/*.js
```

البناء يرفض أي محتوى ناقص أو مخالف للمخطط. القواعد الكاملة والحقول المطلوبة في [`docs/content-guide.md`](../docs/content-guide.md)، وقائمة الفحص في [`docs/qa-checklist.md`](../docs/qa-checklist.md).
