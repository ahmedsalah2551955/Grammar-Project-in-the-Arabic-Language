# نَحْو — منصة النحو العربي

منصة تفاعلية عربية بالكامل لتعلّم النحو العربي لطلاب الصف الثالث الإعدادي. تعمل دون خادم خلفي، ومن دون إنترنت، وعلى الهاتف، مع حفظ التقدم محليًا.

> **الحالة الحالية:** اكتملت **الحزمة الخامسة** من خطة التنفيذ: لوحة التقدم كاملةً (النسبة العامة، السلسلة، القطع المحلولة، الدروس المتقنة، شريط بخمسة مقاطع لكل درس، أقوى الدروس وأضعفها، وسجل آخر الاختبارات)، والاختبار المختلط كاملًا (اختيار الدروس والمستوى والمؤقت وعدد الأسئلة، بدون تغذية راجعة أثناء الحل، إنهاء تلقائي عند انتهاء الوقت، تسجيل الأخطاء)، وشاشة اختبار موقوت بالكامل، والسلسلة اليومية في الرئيسية ولوحة التقدم. ما زال محتوى القطع للدروس ٢–٥ بحالة «قيد الإعداد» إلى أن تصل الحزم التالية.

## ما يعمل الآن

- واجهة عربية RTL متجاوبة، موبايل أولًا، بألوان هادئة ووضعين نهاري وليلي.
- راوتر Hash يعمل عبر `file://` و`http://`، بمسارات للدروس والمستويات والتدريب والنتيجة ولوحة التقدم والأخطاء والاختبار والإعدادات.
- تخزين محلي `nahw.v1` بإصدار ودمج آمن للبيانات القديمة، وحفظ إعدادات المظهر والجلسة والمؤقت.
- **الرئيسية تعرض الدروس الـ٥٣** في تسعة أقسام قابلة للطي، بأرقام الدرس وعنوانه وحالته ومؤشرات مستوياته، مقروءة من ملف بيانات مولّد.
- **صفحات الدروس ١–٥ كاملة**: شرحٌ من ٣ إلى ٦ أسطر، وجدول قاعدة، وخمسة أمثلة معربة بجدول إعراب لكل مثال، وصندوق «تذكّر»، وزر «ابدأ التدريب»، وتنقّل بين الدروس.
- **صفحات «قيد الإعداد»** لبقية الدروس الـ٤٨، توضّح حالتها وتفتح الدرس الجاهز الأول.
- **محرّك تدريب كامل** (`js/engine.js`): يبني الجلسة من بنك القطع، ويقدّم السؤال واحدًا في كل مرة (اختيار أو ضغط على كلمة)، ويعرض «أحسنت!» أو «حاول مرة أخرى» مع التفسير، ويحتسب النسبة.
- **شاشة النتيجة**: «جبت X من Y» والنسبة المئوية، وإعلان فتح المستوى التالي عند ٧٠٪، ونجمة الإنجاز، وتاج الإتقان عند ٨٠٪ في المستوى الخامس، ومراجعة كل خطأ مع إجابتك والصحيحة والتفسير.
- **المستويات حقيقيّة**: قفل، ونجمة، وأفضل نتيجة، وعدد القطع المحلولة، وشرح شرط الفتح، وملاحظة عند تفعيل «فتح كل المستويات».
- **مراجعة الأخطاء تفاعلية**: أعد محاولة السؤال المحفوظ، ومن يجيب إجابة صحيحة يُزال الخطأ من القائمة.
- **بنك قطع تدريبي** للدرس الأول (١٥ قطعة و٤٥ سؤالًا في خمسة مستويات) ليجري المحرك دورةً كاملةً.
- **لوحة التقدم كاملة** (`js/screens/dashboard.js`): النسبة العامة والسلسلة والقطع المحلولة والدروس المتقنة، وشريط بخمسة مقاطع ملوّنة لكل درس، وأقوى الدروس وأضعفها، وسجل آخر ثلاثة اختبارات، وزر «راجع أخطائي».
- **الاختبار المختلط كامل** (`js/exam.js` و`js/screens/exam.js`): اختيار عدة دروس (أو كل الدروس الجاهزة)، ومستوى واحد أو كل المستويات، ومؤقت بدون/١٠/٢٠/٣٠ دقيقة (الافتراضي من الإعدادات)، وعدد ١٠/٢٠/٣٠ سؤالًا مع اقتصاصٍ تلقائي عند نقص المتاح، وعشوائية كاملة دون تغذية راجعة أثناء الحل، وإنهاء تلقائي عند انتهاء الوقت، ونتيجة ومراجعة كاملة بعد الإنهاء. الاختبارات لا تفتح المستويات، لكنها تُضيف أخطاءها إلى قائمة المراجعة.
- **السلسلة اليومية** تزيد عند أول إجابة في اليوم (في التدريب أو في الاختبار)، وتعاد الضبط بعد انقطاع يوم، وتُعرض في الرئيسية ولوحة التقدم مع تقويم الأسبوع.
- **الرئيسية** تعرض الآن: سلسلة الأيام وتقويمها، وشريط التقدم العام، وزرّ «متابعة التدريب» (يفتح آخر مستوى تدربت عليه)، و«اختبار سريع»، وليس مجرد سلسلة في الزاوية.
- **مخطط بيانات موثّق** لملفات الدروس والقطع في `content/` مع دليل كامل في [`docs/content-guide.md`](docs/content-guide.md).
- **مدقّق محتوى** (`tools/validate_content.py`) يفحص البنية والتشكيل والمعرفات وعدد القطع والأسئلة، ويفصل الأخطاء عن التحذيرات.
- **باني بيانات** (`tools/build_data.py`) يشغّل التحقق أولًا، ويرفض البناء عند أي محتوى ناقص، ثم يولّد `data/*.js`.
- شاشة إعدادات فعلية: المظهر، فتح كل المستويات، حجم جلسة التدريب، المؤقت الافتراضي للاختبار، مسح التقدم، والتثبيت.
- هيكل PWA: `manifest.webmanifest` و`sw.js` وأيقونات ١٩٢ و٥١٢ بكسل.
- خطا **Cairo** (الواجهة) و**Amiri** (النصوص المشكولة) محليان بصيغة woff2، دون أي اتصال خارجي وقت التشغيل.

## التشغيل

### الطريقة الأولى: فتح مباشر

افتح `index.html` في المتصفح. تعمل الواجهة والراوتر والتخزين وبيانات الدروس بهذه الطريقة. لا يعمل تسجيل عامل الخدمة أو تثبيت التطبيق لأن المتصفحات تقيّد PWA على بروتوكولات آمنة.

### الطريقة الثانية: خادم محلي (يُنصح بها)

```bash
python3 serve.py
```

سيطبع الخادم رابط الجهاز ورابط الشبكة المحلية للهاتف، ويفتح المتصفح تلقائيًا. للإيقاف اضغط `Ctrl+C`.

خيارات إضافية:

```bash
python3 serve.py --port 8080
python3 serve.py --no-browser
```

## المحتوى والبناء

```bash
python3 tools/validate_content.py    # فحص المحتوى وطباعة التقرير
python3 tools/build_data.py          # فحص ثم توليد data/*.js
```

- المصدر الوحيد هو `content/`: `lessons.json` لبيانات الدروس ومحتواها، و`content/passages/Lxx/levelY.json` لبنوك القطع.
- `data/lessons.js` و`data/Lxx.js` و`data/build-info.json` مولّدة آليًا؛ لا تُعدّل يدويًا.
- الدروس **١–٥** مكتوب محتواها كاملًا في `content/lessons.json` (شرح، جدول قاعدة، ٥ أمثلة معربة، تذكّر)، وبقية الدروس `ready: false` فتظهر «قيد الإعداد».
- بنك القطع التدريبي للدرس الأول في `content/passages/L01/` (خمسة مستويات × ٣ قطع). وهو **بنك مسوّدة**: يحوي الحقل `"draft": true` فيرفعه المدقّق من خطأ إلى تحذير عند نقص العدد، وتبقى بقية القواعد (التشكيل، نوع السؤال، فهرس الإجابة، تكرار المعرفات) أخطاء. تُحذف العلامة عند اكتمال البنك بـ ١٠ قطع لكل مستوى في الحزمة السادسة.
- **البناء يرفض المحتوى الناقص**: درس جاهز بلا شرح أو جدول أو ٥ أمثلة أو تذكّر، أو مستوى ناقص القطع، أو معرفات مكررة، أو إجابة خارج نطاق الخيارات، أو نص غير مشكول.
- بعد أي تغيير في المحتوى: بَثّ `CACHE_NAME` في `sw.js` كي تصل النسخة الجديدة إلى التخزين دون اتصال عند التقديم عبر HTTP. وينبّهك الباني تلقائيًا عند تغيّر مصادر المحتوى.

## المسارات الحالية

| المسار | الشاشة | الحالة |
|---|---|---|
| `#/` | الرئيسية | جاهزة: خريطة الدروس الـ٥٣ من ملف البيانات |
| `#/lesson/1` … `#/lesson/5` | صفحة الدرس | جاهزة: شرح وجدول قاعدة وخمسة أمثلة معربة و«تذكّر» |
| `#/lesson/6` … `#/lesson/53` | صفحة الدرس | قيد الإعداد: رسالة واضحة وزر رجوع |
| `#/lesson/2/levels` | المستويات | جاهزة: قفل ونجوم وأفضل نتيجة وعدد القطع المحلولة |
| `#/lesson/2/levels/1` | التدريب | جاهزة: قطعة مشكولة وسؤال واحد في كل مرة وتغذية راجعة فورية |
| `#/result/2/1` | النتيجة | جاهزة: النسبة وفتح المستوى والإتقان ومراجعة الأخطاء |
| `#/dashboard` | لوحة التقدم | جاهزة بالكامل: إحصاءات، شريط لكل درس، سجل الاختبارات |
| `#/mistakes` | مراجعة الأخطاء | جاهزة: إعادة محاولة وتُحذف الأخطاء المُتقنة |
| `#/exam` | الاختبار المختلط | جاهزة: اختيار وعشوائية ومؤقت وإنهاء تلقائي ومراجعة |
| `#/settings` | الإعدادات | جاهزة وظيفيًا |

## التخزين

- المفتاح: `nahw.v1`.
- البنية: `settings` و`lessons` و`mistakes` و`seenPassages` و`solvedPassages` و`streak` و`examHistory` و`totals`.
- `examHistory` تسجل آخر الاختبارات (الدرس، المستوى، عدد الأسئلة المُجابة، النسبة، التاريخ)، وتُعرض أحدثها أولًا في لوحة التقدم، ويحتفظ البناء بآخر ٣٠ سجلًا فقط.
- `lessons.{id}.levels.{n}` يحوي: `bestScore` و`lastScore` و`attempts` و`passed` و`stars` و`completedAt` و`lastAt` و`lastReview` (ملخّص آخر جلسة مع مراجعة أخطائها، فيبقى ظاهرًا بعد إعادة التحميل).
- `mistakes` مفاتيحه `معرّف_القطعة:معرّف_السؤال`، وقيمته تحفظ نص السؤال وإجابتك والصحيحة والتفسير ونوع السؤال وخياراته، فتُبنى المراجعة منه دون الحاجة إلى بيانات القطع.
- عند تلف البيانات، تُحفظ نسخة تشخيصية تحت `nahw.v1.corrupt` وتُعاد الحالة الافتراضية.
- «مسح التقدم» في الإعدادات يحذف التقدم ويُبقي إعدادات المظهر والجلسة.
- لا يعمل التخزين في بعض سياقات التصفح الخاصة؛ تعرض المنصة تنبيهًا واضحًا حينها.

## الخطوط

- **Cairo** — الواجهة والعناوين.
- **Amiri** — القطع والأمثلة المشكولة.
- كلاهما مرخّص تحت SIL Open Font License 1.1. النص الكامل في [`assets/fonts/OFL.txt`](assets/fonts/OFL.txt).

## المرحلة التالية

الحزمة السادسة: محتوى القطع على خمس دفعات — درس واحد في كل مرة، من الدرس الأول حتى الخامس، مع تشغيل المدقق بعد كل درس، حتى يبلغ المجموع ٢٥٠ قطعة و٦٥٠ سؤالًا ويُلغى وضع المسوّدة.

## ملاحظات تقنية

- لا React ولا npm ولا خطوة بناء للواجهة.
- السكربتات تقليدية (classic scripts) وليست ES Modules، حتى تعمل عبر `file://`.
- لا تُستخدم `fetch` لتحميل بيانات الدروس؛ تُولَّد ملفات `data/*.js` وتُحمَّل عبر `<script>` (ساكنًا للبيانات العامة، وديناميكيًا لبنوك القطع).
- لا توجد طلبات خارجية وقت التشغيل، ولا تتبّع.
- جميع الأرقام المعروضة بالصيغة العربية الهندية (٠١٢٣٤٥٦٧٨٩).
