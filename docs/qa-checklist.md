# قائمة فحص الجودة — منصة نَحْو

قائمة عملية تُنفَّذ بعد كل حزمة، مبنية على القسم ١٢ من الخطة. تُراجَع يدويًا قبل التسليم، ويُحفظ ناتج الفحص الآلي في سجل الحزمة.

---

## ١) المحتوى

- [ ] `python3 tools/validate_content.py` يخرج بصفر أخطاء.
- [ ] كل تحذير مذكور سببًا في سجل الحزمة (مثل `banks-pending` أثناء انتظار بقية القطع).
- [ ] كل درس جاهز فيه: شرح ٣–٦ أسطر، جدول قاعدة، ٥ أمثلة معربة، صندوق «تذكّر».
- [ ] كل جملة مثال وقطعة **مشكولة بالكامل** (نسبة التشكيل ١٠٠٪ مفضَّلة، والحد الأدنى ٨٥٪).
- [ ] كل مثال: كل كلمة في الجملة لها مدخل إعراب (كلمة + إعراب + علامة).
- [ ] معرّفات القطع بصيغة `L{درس:02d}-L{مستوى}-{تسلسل:04d}`، ومعرّفات الأسئلة `q1`، `q2`… بالترتيب.
- [ ] لا تكرار في النصوص بعد تجريد التشكيل، ولا تكرار في المعرّفات.
- [ ] كلمة إجابة سؤال «الضغط» ترد في النص **مرة واحدة بالضبط**.
- [ ] عدد الأسئلة يطابق نطاق المستوى (١ / ٢ / ٣ / ٣–٤ / ٤–٥).
- [ ] الطول يطابق نطاق المستوى (٣–٦ كلمات، ٦–١٠ كلمات، جملتان، ٢–٣ جمل، ٣–٤ جمل).
- [ ] مراجعة لغوية يدوية: الإصحاح، التشكيل، مناسبة المستوى، وحدود الدرس (لا مصطلح من درس لاحق).

## ٢) التشغيل

- [ ] فتح `index.html` مباشرة عبر `file://` يعمل بلا أخطاء.
- [ ] التشغيل عبر `serve.py` (أو أي خادم ثابت) يعمل بلا أخطاء.
- [ ] عامل الخدمة يسجَّل بنجاح ويخزّن هيكل التطبيق، والتخزين دون اتصال يعمل.
- [ ] بعد أي تغيير في الأصول المخزَّنة: بَثّ `CACHE_NAME` في `sw.js`.

## ٣) التدريب (الحزمة الرابعة)

- [ ] القطعة معروضة بخط Amiri مشكولة، والمصدر ومعرّف القطعة ظاهران.
- [ ] السؤال **واحد في كل مرة**، مع شريط تقدّم يعرض القطعة والسؤال وعدد الإجابات الصحيحة.
- [ ] أسئلة `mcq` و`fill` و`transform` تعرض خيارات مخلوطة مع بقاء الإجابة الصحيحة في مكانها.
- [ ] سؤال `tap` يعرض كلمات النص أزرارًا، وتُقبل الكلمة الصحيحة مرة واحدة فقط.
- [ ] التغذية الراجعة فورية: «أحسنت!» أو «حاول مرة أخرى» ثم التفسير، مع `aria-live`.
- [ ] زر «السؤال التالي»، ثم «القطعة التالية»، ثم «عرض النتيجة».
- [ ] النتيجة تعرض «جبت X من Y» والنسبة ورسالة تشجيعية.
- [ ] النجاح عند ٧٠٪: يظهر إعلان الفتح، ويظهر زر المستوى التالي.
- [ ] الفشل لا يمنح نجاحًا ولا نجمة، وأفضل نتيجة لا تنقص.
- [ ] المستوى الخامس بنسبة ٨٠٪ فأكثر ⟵ الدرس «متقن» مع تاج الإتقان.
- [ ] لا تتكرر القطعة داخل الجلسة، ولا يُعاد استعمالها حتى تنتهي دورة البنك.
- [ ] «فتح كل المستويات» يسمح بالدخول فقط، ولا يمنح نجاحًا أو نجمة.
- [ ] شاشة النتيجة تبقى بعد إعادة التحميل (تُحفظ مراجعة آخر جلسة).

## ٤) مراجعة الأخطاء

- [ ] كل خطأ محفوظ بمعرّف القطعة والسؤال، ومعه نص السؤال وإجابتك والصحيحة والتفسير.
- [ ] إعادة المحاولة متاحة، ومن يجيب إجابة صحيحة يُزال الخطأ من القائمة.
- [ ] بقاء الخطأ عند الإجابة الخاطئة مع إظهار الإجابة الصحيحة.

## ٥) التقدم والتخزين

- [ ] التقدم يبقى بعد إعادة التحميل (المستويات، النجوم، أفضل نتيجة، الأخطاء، القطع المحلولة).
- [ ] «مسح التقدم» يمسح التقدّم ويُبقي الإعدادات.
- [ ] السلسلة اليومية تزيد مرة واحدة في اليوم وتُعيد الضبط بعد انقطاع يوم، ويظهر في الرئيسية ولوحة التقدم.
- [ ] لوحة التقدم تعرض: النسبة العامة، السلسلة، القطع المحلولة من المتاح، الدروس المتقنة، وأقوى/أضعف الدروس.
- [ ] شريط لكل درس من خمس مقاطع بألوان المستويات، بحسب الحالة (ناجح / قيد التدريب / متاح / مقفل).
- [ ] «آخر الاختبارات» يعرض أحدث الاختبارات (العدد والنسبة والتاريخ).

## ٥-ب) الاختبار المختلط

- [ ] اختيار عدة دروس (أو كل الدروس الجاهزة)، ومستوى واحد أو كل المستويات.
- [ ] مؤقت اختياري: بدون / ١٠ / ٢٠ / ٣٠ دقيقة، والافتراضي مأخوذ من الإعدادات.
- [ ] عدد الأسئلة ١٠ / ٢٠ / ٣٠، مع اقتصاصٍ تلقائي عند نقص المتاح.
- [ ] عشوائية كاملة في ترتيب الأسئلة، ودون تغذية راجعة أثناء الحل.
- [ ] اختيار الإجابة وتغييرها قبل «التالي»؛ وقد تُترك بلا اختيار.
- [ ] إنهاء تلقائي عند انتهاء الوقت، مع الاحتفاظ بما أُجيب فقط.
- [ ] النتيجة والمراجعة بعد الإنهاء، دون فتح أي مستوى ودون نجوم.
- [ ] الأخطاء تُضاف إلى قائمة المراجعة؛ تظهر مع نص السؤال وإجابتك والصحيحة والتفسير.
- [ ] سجل الاختبار يُحفظ في `examHistory`، ويبقى بعد إعادة التحميل، وتُعرض في لوحة التقدم.

## ٦) التصميم وإمكانية الوصول

- [ ] لا فيضيق أفقي على ٣٢٠ و٥٠٠ و١٠٨٠ بكسل.
- [ ] الوضعان النهاري والليلي واضحان في كل شاشات الحزمة.
- [ ] أزرار اللمس ٤٨ بكسل على الأقل، والنصوص العربية فقط.
- [ ] لوحة المفاتيح: يمكن الوصول إلى الخيارات وتفعيلها بـ Enter وTab.
- [ ] `prefers-reduced-motion` مُحترم.
- [ ] الأرقام بالصيغة العربية الهندية في كل الواجهات.
- [ ] لا أخطاء في وحدة التحكم، ولا طلبات خارجية وقت التشغيل.
