# دليل محتوى منصة نَحْو

هذا الدليل يشرح مخطط البيانات المعتمد، وقواعد كتابة الدروس والقطع، وطريقة التحقق والبناء. الهدف أن يكتب أي مُعدّ محتوى ملفات تمرّ الفحص من أول مرة، وأن يرفض البناء تلقائيًا أي محتوى ناقص أو مخالف.

---

## ١. خط البيانات

```text
content/*.json  →  tools/validate_content.py  →  tools/build_data.py  →  data/*.js  →  التطبيق
```

- المصدر الوحيد للتعديل هو مجلد `content/`.
- ملفات `data/*.js` مولّدة آليًا؛ لا تُعدّل يدويًا أبدًا.
- الأدوات بمكتبة Python القياسية فقط، ولا تتصل بالشبكة.

---

## ٢. ملف الدروس `content/lessons.json`

```json
{
  "version": 1,
  "lessons": [
    { "id": 1, "title": "الكلمة وأنواعها", "section": "basics", "ready": false }
  ]
}
```

| الحقل | القاعدة |
|---|---|
| `version` | ثابت على `1`. |
| `lessons` | ٥٣ درسًا بالضبط، معرفات `1…53` بالترتيب دون تكرار. |
| `title` | نص عربي من حرفين إلى ٨٠ حرفًا، غير مكرر. |
| `section` | أحد مفاتيح الأقسام التسعة أدناه، ويجب أن يطابق نطاق رقم الدرس. |
| `ready` | `true` يعني درسًا كامل المحتوى، `false` يعني «قيد الإعداد». |

### الأقسام التسعة

| المفتاح | القسم | الدروس |
|---|---|---|
| `basics` | الأساسيات | ١–١٠ |
| `marfoo` | المرفوعات | ١١–١٤ |
| `nawasikh` | النواسخ | ١٥–١٩ |
| `mansoob` | المنصوبات | ٢٠–٢٨ |
| `majroor` | المجرورات | ٢٩–٣٠ |
| `far3i` | العلامات الفرعية | ٣١–٣٦ |
| `tawabi` | التوابع | ٣٧–٤٠ |
| `af3al` | إعراب الفعل والأساليب | ٤١–٤٨ |
| `mushtaqqat` | المشتقات | ٤٩–٥٣ |

### محتوى الدرس الجاهز (`ready: true`)

الدرس الجاهز يجب أن يضيف أربعة حقول، وإلا رفض البناء:

```json
{
  "explanation": ["سطر شرح قصير.", "سطر ثانٍ.", "سطر ثالث."],
  "ruleTable": {
    "title": "علامات الاسم",
    "headers": ["العلامة", "مثال"],
    "rows": [["أل", "الْكِتَابُ"], ["التنوين", "كِتَابٌ"]]
  },
  "examples": [
    {
      "sentence": "الْكِتَابُ جَدِيدٌ.",
      "parsing": [
        { "word": "الْكِتَابُ", "role": "مبتدأ", "sign": "مرفوع وعلامة رفعه الضمة الظاهرة." }
      ]
    }
  ],
  "tip": ["لا تحكم على الكلمة من معناها فقط؛ ابحث عن علامة ظاهرة."]
}
```

| الحقل | القاعدة |
|---|---|
| `explanation` | ٣–٦ أسطر، كل سطر نص غير فارغ. |
| `ruleTable` | `title` غير فارغ، `headers` ٢–٤ رؤوس، `rows` صفان فأكثر وكل صف بطول الرؤوس. |
| `examples` | ٥ أمثلة بالضبط؛ لكل مثال `sentence` مشكولة بالكامل و`parsing` إعراب كامل (`word` و`role` و`sign`). |
| `tip` | ١–٦ ملاحظات للأخطاء الشائعة. |

### الدروس المنشورة حاليًا

| الدرس | العنوان | الحالة |
|---|---|---|
| ١ | الكلمة وأنواعها | منشور كاملًا |
| ٢ | علامات الاسم | منشور كاملًا |
| ٣ | علامات الفعل | منشور كاملًا |
| ٤ | علامات الحرف | منشور كاملًا |
| ٥ | التعريف والتنكير | منشور كاملًا |
| ٦–٥٣ | بقية المنهج | `ready: false` — تظهر «قيد الإعداد» |

### أسلوب الكتابة المتَّبع

- **النصّ المجلوب** (الشرح والأمثلة وملاحظات «تذكّر») يُكتب مشكولًا بالكامل بخط Amiri عند العرض.
- **علامات الإعراب** في حقل `sign` تُكتب بلا تشكيل كما هي في الكتب المدرسية: «مرفوع وعلامة رفعه الضمة الظاهرة».
- **جملة المثال** تُشمَل كلمةً كلمةً: كل كلمة في الجملة لها مدخل في `parsing`، ولا تُترك كلمة بلا إعراب.
- **أمثلة الدرس** تلتزم بالدرس الحالي والدروس السابقة فقط، فلا يُستعمل في الدرس الأول مصطلحٌ من المنصوبات أو المرفوعات المتقدّمة.
- **جدول القاعدة** يشرح ما يميّز الدرس (علامات الاسم، أنواع الفعل، …) لا ما يأتي في الدروس اللاحقة.
- **صندوق «تذكّر»** يذكر الخلط الشائع عند الطالب: مثل الحكم من المعنى وحده، أو خلط الاسم بالحرف.

## ٣. بنوك القطع `content/passages/Lxx/levelY.json`

كل درس جاهز له مجلد `content/passages/L{رقم الدرس:02d}` (مثل `L01`) وفيه خمسة ملفات: `level1.json` حتى `level5.json`. المجلدات التي يبدأ اسمها بشرطة سفلية (مثل `_template`) قوالب لا تُفحص.

### ما هو مُسلَّم حاليًا

| الدرس | الحالة | القطع | الأسئلة |
|---|---|---|---|
| ١ الكلمة وأنواعها | بنك مسوّدة (`draft`) | ١٥ (٣ في كل مستوى) | ٤٥ |
| ٢–٥ | لم تُسلَّم بعد | ٠ | ٠ |

بنك الدرس الأول مسوّدة لأنه يُستكمل في الحزمة السادسة إلى ١٠ قطع لكل مستوى (٥٠ قطعة و١٣٠ سؤالًا للدرس الواحد).

```json
{
  "lesson": 2,
  "level": 1,
  "passages": [
    {
      "id": "L02-L1-0001",
      "lesson": 2,
      "level": 1,
      "text": "هَذَا الْكِتَابُ الْجَدِيدُ نَافِعٌ.",
      "source": "من الحياة اليومية",
      "questions": [
        {
          "id": "q1",
          "type": "mcq",
          "prompt": "مَا الْعَلَامَةُ الَّتِي تَدُلُّ عَلَى أَنَّ «الْكِتَابُ» اسْمٌ؟",
          "options": ["قَبُولُ «أَلْ»", "قَبُولُ تَاءِ الْفَاعِلِ", "قَبُولُ نُونِ التَّوْكِيدِ"],
          "answer": 0,
          "explain": "«الْكِتَابُ» اسْمٌ لِأَنَّهُ يَقْبَلُ «أَلْ»."
        }
      ]
    }
  ]
}
```

### القواعد العامة

- عدد القطع: **١٠ لكل مستوى** في كل درس جاهز (٥٠ قطعة لكل درس).
- المعرف: `L{رقم الدرس:02d}-L{المستوى}-{التسلسل:04d}` والتسلسل متصل من `0001`.
- حقلي `lesson` و`level` داخل الملف وداخل كل قطعة يطابقان المجلد والملف.
- النص مشكول بالكامل، والمصدر نص غير فارغ (مثل: حِكم، أمثال، مدرسة، أسرة، طبيعة).
- معرفات الأسئلة `q1` و`q2`… بالترتيب داخل القطعة.
- لكل سؤال إجابة صحيحة وتفسير قصير (حتى ٢٤٠ حرفًا).
- الأسئلة تلتزم بالدرس الحالي والدروس السابقة فقط.
- لا يتكرر نص قطعتين، ولا يتكرر معرف قطعة، ولا يتكرر خيار حرفيًا.

### قواعد المستويات

| المستوى | طول النص | أسئلة القطعة |
|---|---|---|
| ١ سهل | ٣–٦ كلمات | سؤال واحد |
| ٢ سهل متوسط | ٦–١٠ كلمات | سؤالان |
| ٣ متوسط | جملتان | ٣ أسئلة |
| ٤ صعب متوسط | ٢–٣ جمل | ٣–٤ أسئلة |
| ٥ صعب | ٣–٤ جمل | ٤–٥ أسئلة |

الخروج عن نطاق الأسئلة **خطأ** يمنع البناء، والخروج عن نطاق الطول **تحذير** يظهر في التقرير.

### أنواع الأسئلة

| النوع | الحقول | قواعد الإجابة |
|---|---|---|
| `mcq` | `options` (٣ فأكثر)، `answer` | `answer` فهرس يبدأ من صفر داخل نطاق الخيارات. |
| `fill` | `options` (٢ فأكثر)، `answer` | مثل `mcq`؛ خيار واحد صحيح يكمل الفراغ. |
| `transform` | `options` (٢ فأكثر)، `answer` | الخيارات جمل كاملة بعد التحويل، وفهرس الجملة الصحيحة. |
| `tap` | `answer` نص | كلمة واحدة تظهر في نص القطعة **مرة واحدة بالضبط** بعد تجريد التشكيل والترقيم؛ غير ذلك خطأ. |

تُخلط خيارات `mcq` عند العرض في الواجهة مع الحفاظ على الإجابة الصحيحة، فلا حاجة لخلطها في الملف.

### بنك مسوّدة (`draft`)

الحقل `"draft": true` في جذر ملف المستوى يخفض **عدد القطع** من خطأ إلى تحذير:

```json
{
  "lesson": 1,
  "level": 1,
  "draft": true,
  "passages": [ "…" ]
}
```

- الغرض: بنوك تدريجية تُسلَّم على دفعات (كتلة رابعة) ثم تُستكمل في الحزمة السادسة.
- ما يبقى **خطأً** في البنك المسوّدة: التشكيل، نوع السؤال، فهرس الإجابة، تكرار المعرّفات، تكرار النصوص، كلمة `tap` غير الظاهرة مرة واحدة، عدد الأسئلة خارج نطاق المستوى.
- ما يصبح **تحذيرًا**: نقص عدد القطع عن ١٠، وغياب ملف مستوى (الرمز `level-missing-draft`).
- عند اكتمال البنك بحذف `"draft"` يعود الفحص إلى الحزم الكامل، ويصبح نقص العدد خطأً من جديد.

### أسئلة الفراغ والتحويل

في `fill` و`transform` يكون الاختلاف بين الخيارات في **آخر الكلمة** (الضمة والكسرة والفتحة) هو المقصود، فلا يُنبَّه على تشابه الحروف في هذه الأنواع. مثلًا:

```json
{
  "id": "q1",
  "type": "fill",
  "prompt": "أَكْمِلْ بِاخْتِيَارِ الْكَلِمَةِ الصَّحِيحَةِ: قَرَأَ الطَّالِبُ ...",
  "options": ["الدَّرْسَ", "الدَّرْسِ", "دَرْسٌ"],
  "answer": 0,
  "explain": "الْمَفْعُولُ بِهِ مَنْصُوبٌ، وَعَلَامَةُ نَصْبِهِ الْفَتْحَةُ الظَّاهِرَةُ، فَالْكَلِمَةُ «الدَّرْسَ»."
}
```

## ٤. التشكيل

يعتبر الفاحص النص مشكولًا بالكامل إذا حمل ٨٥٪ فأكثر من الحروف المعرّبة حركةً (تُستثنى حروف المد: ا و ي ى، وتُحسب الشدّة حركةً). النصوص المشكولة جزئيًا تُرفض بـ `error` في نص القطع وجمل الأمثلة، وتظهر بـ `warning` في نصوص الأسئلة.

## ٥. تشغيل الأدوات

```bash
python3 tools/validate_content.py    # فحص فقط ويطبع التقرير
python3 tools/build_data.py          # يفحص أولًا ثم يولّد data/*.js
```

- رمز الخروج `0` عند السلامة، و`1` عند وجود أخطاء.
- **البناء يرفض أي محتوى ناقص**: درس جاهز بلا شرح أو جدول أو ٥ أمثلة أو تذكّر، أو قطع ناقصة العدد، أو معرفات مكررة، أو إجابة خارج نطاق الخيارات، أو كلمة `tap` غير ظاهرة مرة واحدة، أو نص غير مشكول.
- التحذيرات لا تمنع البناء؛ لكنها تُظهرها التقرير لتُعالَج.
- عند نجاح البناء تتحدث ملفات `data/lessons.js` و`data/Lxx.js` و`data/build-info.json`، ويطبع البناء تذكيرًا ببَثّ `CACHE_NAME` في `sw.js` إن تغيّر مصدر المحتوى (كي تصل النسخة الجديدة للتخزين دون اتصال).

### أمثلة أخطاء يرفضها البناء

| الرمز | المعنى |
|---|---|
| `lesson-content-missing` | درس `ready: true` بلا أحد حقول المحتوى الأربعة. |
| `examples-count` | عدد الأمثلة ليس ٥. |
| `passage-count` | عدد القطع في مستوى ليس ١٠ (ويتحوّل إلى تحذير `passage-count-draft` في البنك المسوّدة). |
| `level-missing` | ملف مستوى مفقود من بنك الدرس (ويتحوّل إلى تحذير `level-missing-draft` في البنك المسوّدة). |
| `tashkeel` | نص قطعة أو جملة مثال غير مشكولة بالكامل. |
| `id-duplicate` / `text-duplicate` | تكرار معرف قطعة أو نصها. |
| `answer-range` | فهرس الإجابة خارج نطاق الخيارات. |
| `tap-word` | كلمة سؤال الضغط غير ظاهرة مرة واحدة بالضبط. |
| `question-count` | عدد أسئلة القطعة خارج نطاق مستواها. |
| `section-range` | درس موضوع في قسم لا يطابق نطاق رقمه. |

## ٦. ترتيب الإضافة لاحقًا

1. اكتب بنك الدرس في `content/passages/Lxx/` (خمسة ملفات مستويات).
2. اجعل الدرس `ready: true` وأضف محتواه الكامل في `lessons.json` عند توفره.
3. شغّل `python3 tools/build_data.py`؛ لن يُقبل البناء إلا بمحتوى مكتمل.
4. بعد كل تغيير في المحتوى: بَثّ إصدار مخزن `sw.js` عند التقديم عبر HTTP.

الأداة `add_passages.py` لإضافة دفعات من CSV/JSON ستُضاف في الحزمة السابعة وفق الأعمدة المقررة في الخطة.
